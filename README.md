# HV-RDAC

Исследовательский резистивный ЦАП как силовой каскад с выходным трансформатором.
Сейчас: **низковольтная симуляция 4-битного ядра**, не готовый усилитель 5–10 Вт.

## Где что лежит

- `docs/` — исходный brief, план, допущения и сравнение архитектур.
- `calc/architecture.py` — расчёт идеального трансформатора и источника Тевенина.
- `sim/run_phase_a.py` — генерация схем, запуск ngspice и проверки.
- `sim/generated/*.cir` — полные независимые SPICE-схемы с ключами и источниками.
- `results/` — измеренные значения JSON, осциллограммы CSV и журнал ngspice.
- `plots/` — графики кодов, синуса, спектра и major carry.
- `kicad/hv_rdac_core.kicad_pro` — первый проект KiCad: редактируемое пассивное ядро.

## Запуск (PowerShell, из корня проекта)

```powershell
python -m pip install -r requirements.txt
python calc/architecture.py
python sim/run_phase_a.py
```

Проверенное окружение: Python 3.13.3, KiCad 10.0.1, ngspice 46 shared library.
По умолчанию DLL: `C:\Program Files\KiCad\10.0\bin\ngspice.dll`.
Другой путь можно указать в переменной `NGSPICE_DLL`. Адаптер пока рассчитан на Windows.
Запускать симулятор через графический интерфейс не требуется.
При отдельном ngspice CLI схемы можно запускать, например,
`ngspice -b -r output.raw sim/generated/code_sweep.cir`.

## KiCad

Откройте `kicad/hv_rdac_core.kicad_pro`, затем схему `hv_rdac_core.kicad_sch`.
Первый лист показывает оба R–2R плеча и проверочную нагрузку. Имена сетей соединяют
ветви; D_A0…3 и D_B0…3 обозначают входы от ключей. **Источники, ключи и трансформатор
пока реализованы только в полных SPICE-файлах.** Кнопка симуляции KiCad для этого
пассивного листа ещё не настроена; плата не создана.

Результаты и ограничения: `docs/phase_a_results.md`. Следующие шаги: `docs/plan.md`.
